Template: Integration Contract
```csharp
namespace <Company.Project.Module>;
public interface I<Feature>Service
{
    Task StartAsync(CancellationToken ct);
    Task StopAsync(CancellationToken ct);
    event EventHandler<DataReceivedEventArgs> DataReceived;
}
public sealed record TelemetrySample(
    DateTimeOffset Timestamp,
    double Latitude,
    double Longitude,
    double AltitudeMeters
);
public sealed class DataReceivedEventArgs : EventArgs
{
    public TelemetrySample Sample { get; init; }
    public DataReceivedEventArgs(TelemetrySample sample) => Sample = sample;
}
```
- **Threading:** callbacks on thread-pool; UI components must marshal to UI thread.
- **Errors:** transient faults → retry with jitter; hard faults → fail fast with logs.
